# Zahide Hanım Çiftliği

Doğal ve organik çiftlik ürünleri e-ticaret uygulaması.

## Özellikler

- Ürün kataloğu ve kategorilere göre filtreleme
- Ürün arama
- Alışveriş sepeti
- Favori ürünler
- Kullanıcı hesabı ve kimlik doğrulama
- Türkçe ve İngilizce dil desteği
- Responsive tasarım (mobil, tablet, masaüstü)

## Çalıştırma

```bash
flutter pub get
flutter run -d chrome
```
